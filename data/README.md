# Dataset

This project uses the public **IBM HR Analytics Employee Attrition & Performance** dataset.

The CSV is not redistributed in this repository. To run the notebook locally, place the dataset at:

`data/WA_Fn-UseC_-HR-Employee-Attrition.csv`

The notebook also detects the original Kaggle input path automatically when run on Kaggle.

This project contains no employer HR data.
